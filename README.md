# FORMA — фитнес-тренер через веб-камеру

**Admit Hackathon 2026 · кейс Motion · направление B / Fitness**

Веб-приложение, в котором веб-камера заменяет контроллер. Пользователь открывает ссылку и встаёт перед камерой, дальше управляет всем движениями тела. FORMA считает повторения, следит за техникой и конкретно подсказывает, как исправить ошибку. Ничего устанавливать не нужно.

## Возможности

| | |
|---|---|
| **Приседания** | глубина, колени, спина, пятки — лицом или боком |
| **Джампинг-джек** | амплитуда рук и ног, синхронность, прямые локти |
| **Подъём рук в стороны** | высота, симметрия, плечи, раскачивание корпуса |
| **Планка** | засчитываются только секунды с ровной линией тела |

**Сценарий:** выбор упражнения ладонью → проверка, что тело в кадре и ракурс правильный → отсчёт 3-2-1 → тренировка со счётчиком, подсказками и голосом → итоги: очки, процент чистой техники, главные ошибки с советами, рекорд и график прогресса.

## Жесты

| Жест | Действие |
|---|---|
| Поднять руку и задержать ладонь на кнопке ~1 с | выбрать карточку или кнопку (курсор-ладонь с кольцом прогресса) |
| Встать в кадр в нужном ракурсе | автоматический старт подхода |
| Выполнить движение упражнения | засчитать повтор или секунду планки |
| Скрестить руки над головой на 2 с | завершить подход |
| Встать из планки на 4+ с | завершить планку |

Запасное управление: мышь, `Esc` — стоп, `M` — звук, `D` — отладочная панель с углами.

## Режим «ошибка» (твист)

Каждый кадр упражнение считает углы суставов и пропорции тела по 33 точкам MediaPipe Pose и проверяет их по собственным правилам. Нарушенное правило превращается в ошибку с конкретной подсказкой: **что сделано не так + что изменить**.

- **Устойчивость.** Ошибка показывается, только если держится ≥ 250 мс, и гаснет через 700 мс после исправления. Подсказки не мерцают.
- **Три канала обратной связи.** Красная плашка с текстом, пульсирующие красные суставы на скелете и голосовая подсказка (Web Speech API, одна фраза не повторяется чаще раза в 7 с).
- **Незасчитанные повторы.** Если движение не дотянуто (присед выше параллели, руки ниже плеч, прыжок без разведения ног), попытка не засчитывается, и сразу объясняется почему.
- **Чистые и нечистые повторы.** Повтор с ошибкой засчитывается, но не считается «чистым». Чистые приносят больше очков. В планке таймер цели идёт только при правильной технике.
- **Разбор в итогах.** Какие ошибки были, сколько раз (или сколько секунд) и как исправить.
- **Направляющие на видео.** Линия коленей, до которой надо сесть; линия плеч для подъёма рук; линия «плечо — лодыжка» для планки. Становится зелёной, когда положение верное.

| Упражнение | Что ловим | Как считаем | Подсказка |
|---|---|---|---|
| Приседания | неполная глубина | таз не опустился до ~уровня коленей (глубина по высоте таза относительно длины бедра) | «Опускайся ниже: таз до уровня коленей» |
| | колени внутрь | расстояние между коленями < 80 % расстояния между лодыжками (лицом) | «Разводи колени наружу — по линии носков» |
| | колени за носками | колено дальше носка > 15 % длины голени (боком) | «Отводи таз назад, как будто садишься на стул» |
| | наклон корпуса | линия плечо — таз отклонена от вертикали > 55° | «Раскрой грудь, держи спину ровнее» |
| | пятки отрываются | пятка выше носка > 20 % голени | «Перенеси вес на пятки» |
| | перекос | разница углов в коленях > 22° | «Левое колено сгибается меньше — распредели вес» |
| Джампинг-джек | руки не доходят | кисти поднимаются над плечами меньше чем на 0,7 длины корпуса | «Поднимай руки полностью над головой» |
| | одна рука отстаёт | разница высот кистей в верхней точке | «Левая рука отстаёт — поднимай синхронно» |
| | ноги узко | ширина стоп < 1,3 ширины плеч | «Прыгай шире: стопы шире плеч» |
| | согнутые локти | угол в локте < 140° | «В верхней точке выпрямляй руки» |
| Подъём рук | ниже плеч | угол таз — плечо — кисть < 70° | «Поднимай руки до горизонтали» |
| | выше плеч | угол > 115° | «Останавливайся на уровне плеч» |
| | асимметрия | разница рук > 20° | «Правая рука ниже — поднимай синхронно» |
| | плечи к ушам | расстояние ухо — плечо сократилось > 30 % от калибровки в покое | «Опусти плечи вниз» |
| | раскачивание | корпус отклонился > 10° | «Стой ровно, без рывка корпусом» |
| Планка | таз задран / провис | отклонение таза от прямой плечо — лодыжка | «Опусти таз» / «Подкрути таз, напряги пресс» |
| | согнутые колени | угол в колене < 150° | «Выпрями ноги» |
| | голова опущена | ухо заметно ниже плеча | «Шея продолжает линию спины» |

Также определяются проблемы с кадром: «Тебя не видно целиком», «Встань лицом к камере», «Повернись боком». Ракурс вычисляется по отношению ширины плеч к длине корпуса.

## Запуск

Нужен любой статический сервер: ES-модули и камера не работают при открытии файла через `file://`. Интернет нужен для загрузки модели MediaPipe с CDN.

```bash
# вариант 1 — Python
python -m http.server 8000
# вариант 2 — Node
npx serve .
```

Открыть <http://localhost:8000> и разрешить доступ к камере. Рекомендуется Chrome или Edge.

Нет камеры — на стартовом экране есть кнопка «загрузить видео» (для проверки на записи тренировки).

### Деплой на GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `root`. Сайт откроется по `https://<user>.github.io/<repo>/`. Страницы работают по HTTPS, поэтому камера доступна.

## Технологии и структура

- **MediaPipe Tasks Vision — Pose Landmarker** (33 точки тела, WebAssembly + GPU). На телефоне используется лёгкая модель `lite`, на компьютере — `full`. Модель можно выбрать вручную: `?model=lite`.
- Чистый HTML/CSS/JS без сборки и зависимостей.
- Web Audio API — звуки, Web Speech API — голосовые подсказки, `localStorage` — история и рекорды.

```
index.html   — разметка экранов
style.css    — оформление, адаптив под телефон
script.js    — вся логика:
  2. геометрия (углы, ракурс, сглаживание точек)
  3. каталог ошибок с подсказками
  4. упражнения: фазы движения, подсчёт, правила техники
  5. монитор ошибок (антимерцание, приоритеты)
  6. звук и голос
  7. история и рекорды
  8. отрисовка скелета и направляющих
  9. жесты: курсор-ладонь, скрещённые руки
  10. сценарий: меню → подготовка → отсчёт → тренировка → итоги
```

Вся логика распознавания упражнений, подсчёта и ошибок написана командой. MediaPipe выдаёт только координаты точек тела.
