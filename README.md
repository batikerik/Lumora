# FORMA — фитнес-тренер через веб-камеру

**Admit Hackathon 2026 · кейс Motion · направление B / Fitness**

### Открыть: **<https://lumora2-gamma.vercel.app/>**

Веб-приложение, в котором веб-камера заменяет контроллер. Пользователь открывает ссылку и встаёт перед камерой, дальше управляет всем движениями тела. FORMA считает повторения, оценивает каждый повтор, следит за техникой и конкретно подсказывает, как исправить ошибку. Ничего устанавливать не нужно. Работает на компьютере и на телефоне.

## Как попробовать за минуту

1. Открыть <https://lumora2-gamma.vercel.app/> в Chrome или Edge и нажать **«Включить камеру»**, затем **«Разрешить»**.
2. Отойти от камеры на 2–3 шага, чтобы было видно всё тело.
3. Поднять руку и задержать ладонь на карточке **«Приседания»** примерно на секунду.
4. Выбрать цель кнопками **− / +** (тоже ладонью) и встать в кадр: подход стартует сам после отсчёта 3-2-1.
5. Присесть несколько раз. Одно приседание сделать неглубоким, чтобы увидеть режим «ошибка».
6. Скрестить руки над головой на 2 секунды, чтобы завершить подход и посмотреть итоги.

Нет камеры — на стартовом экране можно загрузить видео с тренировкой.

## Возможности

| Упражнение | Что проверяем | Как считаем |
|---|---|---|
| **Приседания** | глубина, колени, спина, пятки — лицом или боком | повторы + оценка каждого |
| **Джампинг-джек** | амплитуда рук и ног, синхронность, прямые локти | повторы + оценка каждого |
| **Подъём рук в стороны** | высота, симметрия, плечи, раскачивание корпуса | повторы + оценка каждого |
| **Планка** | прямая линия плечи — таз — пятки, ноги, голова | засчитываются только секунды с ровной линией тела |
| **Тренировка** | все 4 упражнения подряд с отдыхом 10 с между ними | общий счёт и итоги |

**Сценарий:** выбор упражнения ладонью → выбор цели жестом → проверка, что тело в кадре и ракурс правильный → отсчёт 3-2-1 → тренировка со счётчиком, подсказками и голосом → итоги: очки, средняя оценка и лучший повтор, главные ошибки с советами, рекорд и график прогресса.

### Режим «Тренировка»
Карточка в меню запускает программу: 8 приседаний → 12 джампинг-джеков → 8 подъёмов рук → 20 секунд планки. Между упражнениями — экран отдыха с таймером, результатом прошлого упражнения и следующим упражнением. В конце — общие итоги: сумма очков, повторы, чистое время планки, средняя техника и главные ошибки по всей тренировке. У тренировки свой рекорд.

### Оценка каждого повтора (0–100 %)
После каждого повтора над счётчиком всплывает «+1 · 92%».
- **Приседания:** глубина (100 % — таз ниже коленей) и симметрия ног.
- **Джампинг-джек:** амплитуда рук и ног, синхронность рук.
- **Подъём рук:** насколько близко к уровню плеч (90°) и насколько руки на одной высоте.
- За каждую ошибку техники в повторе снимается 15 %.

В итогах — средняя оценка и лучший повтор.

## Жесты

| Жест | Действие |
|---|---|
| Поднять руку и задержать ладонь на кнопке ~1 с | выбрать карточку или кнопку (курсор-ладонь с кольцом прогресса) |
| Ладонь на «−» / «+» | изменить цель подхода (запоминается) |
| Встать в кадр в нужном ракурсе | автоматический старт подхода |
| Выполнить движение упражнения | засчитать повтор или секунду планки |
| Скрестить руки над головой на 2 с | завершить подход |
| Встать из планки на 4+ с | завершить планку |

Запасное управление: мышь, `Esc` — стоп, `M` — звук, `D` — отладочная панель с углами.

## Режим «ошибка» (твист)

Каждый кадр упражнение считает углы суставов и пропорции тела по 33 точкам MediaPipe Pose и проверяет их по собственным правилам. Нарушенное правило превращается в ошибку с конкретной подсказкой: **что сделано не так + что изменить**.

- **Устойчивость.** Ошибка показывается, только если держится ≥ 250 мс, и гаснет через 700 мс после исправления. Подсказки не мерцают.
- **Три канала обратной связи.** Красная плашка с текстом, пульсирующие красные суставы на скелете и голосовая подсказка (Web Speech API, одна фраза не повторяется чаще раза в 7 с).
- **Незасчитанные повторы.** Если движение не дотянуто (присед выше параллели, руки ниже плеч, прыжок без разведения ног), попытка не засчитывается, и сразу объясняется почему.
- **Чистые и нечистые повторы.** Повтор с ошибкой засчитывается, но не считается «чистым», получает более низкую оценку и меньше очков. В планке таймер цели идёт только при правильной технике.
- **Разбор в итогах.** Какие ошибки были, сколько раз (или сколько секунд) и как исправить.
- **Направляющие на видео.** Линия коленей, до которой надо сесть; линия плеч для подъёма рук; линия «плечо — лодыжка» для планки. Становится зелёной, когда положение верное.

| Упражнение | Что ловим | Как считаем | Подсказка |
|---|---|---|---|
| Приседания | неполная глубина | таз не опустился до ~уровня коленей (глубина по высоте таза относительно длины бедра) | «Опускайся ниже: таз до уровня коленей» |
| | колени внутрь | расстояние между коленями < 80 % расстояния между лодыжками (лицом) | «Разводи колени наружу — по линии носков» |
| | колени за носками | колено дальше носка > 15 % длины голени (боком) | «Отводи таз назад, как будто садишься на стул» |
| | наклон корпуса | линия плечо — таз отклонена от вертикали > 55° | «Раскрой грудь, держи спину ровнее» |
| | пятки отрываются | пятка выше носка > 20 % голени | «Перенеси вес на пятки» |
| | перекос | разница углов в коленях > 22° | «Левое колено сгибается меньше — распредели вес» |
| Джампинг-джек | руки не доходят | кисти поднимаются над плечами меньше чем на 0,7 длины корпуса | «Поднимай руки полностью над головой» |
| | одна рука отстаёт | разница высот кистей в верхней точке | «Левая рука отстаёт — поднимай синхронно» |
| | ноги узко | ширина стоп < 1,3 ширины плеч | «Прыгай шире: стопы шире плеч» |
| | согнутые локти | угол в локте < 140° | «В верхней точке выпрямляй руки» |
| Подъём рук | ниже плеч | угол таз — плечо — кисть < 70° | «Поднимай руки до горизонтали» |
| | выше плеч | угол > 115° | «Останавливайся на уровне плеч» |
| | асимметрия | разница рук > 20° | «Правая рука ниже — поднимай синхронно» |
| | плечи к ушам | расстояние ухо — плечо сократилось > 30 % от калибровки в покое | «Опусти плечи вниз» |
| | раскачивание | корпус отклонился > 10° | «Стой ровно, без рывка корпусом» |
| Планка | таз задран / провис | отклонение таза от прямой плечо — лодыжка | «Опусти таз» / «Подкрути таз, напряги пресс» |
| | согнутые колени | угол в колене < 150° | «Выпрями ноги» |
| | голова опущена | ухо заметно ниже плеча | «Шея продолжает линию спины» |

Также определяются проблемы с кадром: «Тебя не видно целиком», «Встань лицом к камере», «Повернись боком». Ракурс вычисляется по отношению ширины плеч к длине корпуса.

## Если с камерой что-то не так

Сайт не остаётся пустым: он объясняет, что случилось и что делать.

- **Ещё до включения** на стартовом экране появляется предупреждение, если доступ к камере заблокирован в браузере или страница открыта не по https.
- **Экран ошибки** называет причину (доступ запрещён, камера не найдена, камера занята другой программой, не загрузилась модель) и даёт пошаговую инструкцию. Если камер несколько, можно выбрать другую. Есть кнопки «Попробовать снова» и «Загрузить видео».
- **Во время работы** сайт следит за камерой. Если камера отключилась, показывает чёрный экран (закрыта шторкой) дольше 3 с или изображение зависло дольше 4 с, поверх экрана появляется окно с кнопкой «Переподключить камеру». Когда картинка возвращается, окно закрывается само.
- **Индикатор в углу:** 🟢 камера работает и человек в кадре, 🟡 камера работает, но человека не видно (появляется подсказка отойти подальше), 🔴 проблема с камерой.
- **Долгая загрузка:** если модель грузится дольше 25 с, появляется подсказка проверить интернет и кнопка «Обновить страницу».

## Приватность и данные

- **Видео никуда не отправляется и не сохраняется.** Каждый кадр обрабатывается прямо в браузере и сразу отбрасывается.
- История подходов, рекорды и выбранные цели хранятся в `localStorage` браузера (ключи `forma.history.v1` и `forma.targets.v1`). Сервера и регистрации нет.

## Запуск локально

Нужен любой статический сервер: ES-модули и камера не работают при открытии файла через `file://`. Интернет нужен для загрузки модели MediaPipe с CDN.

```bash
python -m http.server 8000
```

Открыть <http://localhost:8000> и разрешить доступ к камере. Также подходит расширение **Live Server** в VS Code. Рекомендуется Chrome или Edge.

**Демо-режим.** Если положить рядом с `index.html` файл `demo.mp4` (запись приседаний), на стартовом экране появится кнопка «▶ Посмотреть пример»: приседания запустятся на этом видео без камеры.

### Деплой

Проект задеплоен на **Vercel** как статический сайт: без сборки, Framework Preset — `Other`. Каждый `git push` в `main` обновляет сайт автоматически. HTTPS нужен браузеру для доступа к камере, и Vercel его даёт.

## Технологии и структура

- **MediaPipe Tasks Vision — Pose Landmarker** (33 точки тела, WebAssembly + GPU). На телефоне используется лёгкая модель `lite`, на компьютере — `full`. Модель можно выбрать вручную: `?model=lite`.
- Чистый HTML/CSS/JS без сборки и зависимостей.
- Canvas — скелет и направляющие, Web Audio API — звуки, Web Speech API — голосовые подсказки, `localStorage` — история, рекорды и цели.

```
index.html   — разметка экранов
style.css    — оформление, адаптив под телефон
script.js    — вся логика:
  2. геометрия (углы, ракурс, сглаживание точек)
  3. каталог ошибок с подсказками
  4. упражнения: фазы движения, подсчёт, оценка повтора, правила техники;
     программа «Тренировка»
  5. монитор ошибок (антимерцание, приоритеты)
  6. звук и голос
  7. история, рекорды, выбранные цели
  8. отрисовка скелета и направляющих
  9. жесты: курсор-ладонь, скрещённые руки
  10. сценарий: меню → подготовка → отсчёт → тренировка → отдых → итоги;
      ошибки камеры и слежение за её состоянием
```

Вся логика распознавания упражнений, подсчёта, оценки повторов и ошибок написана командой. MediaPipe выдаёт только координаты точек тела.

## Бонусы

- **Собственная логика распознавания** — правила по углам, пропорциям и фазам движения, а не демо-примеры библиотеки
- **Рекорды и прогресс** — рекорд по каждому упражнению и по тренировке, график последних подходов, общая статистика в меню
- **Адаптация под камеру телефона** — лёгкая модель, фронтальная камера, вёрстка под вертикальный экран
- **Звук и визуальные эффекты** — голосовые подсказки, звуки повторов и ошибок, подсветка суставов, всплывающие оценки
